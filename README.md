# CachyOS KDE bootstrap

This repository adds personal applications and configuration to a **fresh CachyOS installation with KDE selected in the installer**. It keeps the installer's Plasma appearance, account defaults, KDE portal, KWallet integration, and Plasma Login Manager. It also restores Fish, gaming tools, Waydroid, printer discovery, Flatpaks, and Synology automounts. The separate `.dotfiles` repository is the source for Umbriel and Noctalia.

## Fresh-install recovery

1. Install CachyOS with **KDE** selected. Let the installer configure hardware, networking, Plasma, and the login manager. Log into Plasma and connect to the network.
2. Install Git if needed: `sudo pacman -S --needed git`.
3. Clone this repository: `git clone git@github.com:ShinobiAoshi/KDE-Bootstrap.git ~/Projects/KDE-Bootstrap`. Restore GitHub SSH credentials first, or use the HTTPS form of this remote temporarily. The deployed SSH config uses Bitwarden's agent for GitHub only.
4. Restore secrets from encrypted storage. Review hardware and Synology settings in the manifests and units.
5. Review the current [cliamp AUR PKGBUILD](https://aur.archlinux.org/packages/cliamp) and its [upstream source](https://github.com/bjarneo/cliamp) before installation. The recipe reviewed for this change was cliamp 2.3.0: it downloaded a SHA256-checked upstream tag, built it with Go, and installed the binary, desktop file, icon, and license. Recheck when the recipe changes. Also review the [waydroid-nvidia-bin AUR recipe](https://aur.archlinux.org/packages/waydroid-nvidia-bin) and [upstream documentation](https://github.com/Shiro836/waydroid-nvidia) before installation. The upstream v0.1.2 recipe reviewed here pins source revisions and SHA256 checksums, installs a patched Waydroid and prebuilt NVIDIA/Venus components, and declares that it provides/conflicts with `waydroid`.
6. Run `cd ~/Projects/KDE-Bootstrap && ./bootstrap.sh` as the normal user. Before making changes, the script checks the KDE baseline, display manager, commands needed by selected phases, and Synology unit validity when mounts are selected. It installs Stow and checks for dotfile conflicts before installing the application manifests.
7. Review the health report and reboot if system updates require it. Missing required configuration causes a nonzero exit status. A second run should be safe. If a Synology unit changed while its share is mounted, close files on that share, unmount it, and rerun the bootstrap.
8. To bring over the current Android instance, run `./backup-waydroid-data.sh` on the old machine. It writes `~/Downloads/waydroid-data.tar.zst`. Copy that private archive beside `bootstrap.sh` on the new machine before running bootstrap. Log out and back in once after installing Waydroid NVIDIA so its `/dev/udmabuf` udev rule applies, then start Waydroid from Plasma or run `waydroid session start`.

This script installs and configures the desired state. It does **not** uninstall packages from an existing installation, import `/etc/skel`, or replace installer Plasma settings.

## What it configures

- The official-repository manifest contains personal additions beyond the current [CachyOS KDE installer profile](https://github.com/CachyOS/New-Cli-Installer/blob/master/net-profiles.toml). KDE apps absent from that profile include Okular, Plasma Disks, and Print Manager. The installer already provides Dolphin, Gwenview, Haruna, Ark, KCalc, Partition Manager, Discover with `fwupd`, KWallet PAM, Konsole, and the KDE portal.
- Fish remains the login shell. Stow deploys its settings, Fisher installs Hydro, and the existing Bitwarden SSH-agent rule stays scoped to GitHub.
- MIME defaults use Dolphin for directories, Brave Origin for web links and HTML, Okular for PDF, Gwenview for images, cliamp for audio, Haruna for video, Ark for archives, qBittorrent for torrents, and Zed for text. The Stow-managed cliamp launcher opens one file through [Konsole's `-e` argument passing](https://docs.kde.org/trunk_kf6/en/konsole/konsole/command-line-options.html), which keeps paths with spaces and special characters together. [Ghostty's `-e` path handling](https://github.com/ghostty-org/ghostty/discussions/2633) has a documented quoting issue; Ghostty remains the preferred daily terminal.
- KDE's KWallet PAM and `ksecretd` supply Secret Service to personal apps. Keep the login password and wallet password aligned if automatic unlocking is desired. Check **System Settings → KDE Wallet** if a personal app cannot store secrets.
- Avahi and CUPS support driverless printer discovery. The installer includes Avahi through `nss-mdns`, so it needs no separate manifest entry. Print Manager handles configured queues. The bootstrap leaves the installer's UFW configuration alone.
- Synology units under `systemd/system/` are installed as automounts. They retain personal server and export paths; check them before running on another network.
- `waydroid-nvidia-bin` replaces the official Waydroid package. It requires NVIDIA open kernel modules, driver 595.71 or newer, `nvidia-drm.modeset=1`, and a Wayland session. The bootstrap downloads the pinned March 12, 2026 x86_64 GAPPS system and MAINLINE vendor images from Waydroid's SourceForge project, verifies them against SHA-256 hashes measured from the current machine, initializes Waydroid, runs `waydroid-nvidia-setup`, starts the system container, and enables the user Venus service for the next login. It preserves an initialized Waydroid installation if its images differ.
- After NVIDIA setup, the bootstrap checks out [casualsnek/waydroid_script](https://github.com/casualsnek/waydroid_script) at commit `48dbfaf34a6ddbe78688c530f9ba1c26522aafb2` and runs only `main.py install libhoudini` for Android 13 with `uv run`. Python packages come from the SHA-256 locked [requirements file](packages/waydroid-script-requirements.lock.txt); the script's pinned Houdini archive is also checked against the SHA-256 measured from this machine before root runs it. The script writes Houdini into Waydroid's system overlay and updates its Android ABI properties. A rerun skips installation when the matching libraries and property are present. If `waydroid-data.tar.zst` is beside `bootstrap.sh`, bootstrap restores it automatically when the Waydroid data directory is absent or empty. When data already exists, it prompts before replacing it and saves the previous directory alongside it. A rerun skips an archive already restored. The archive contains private Android data and is ignored by Git; keep it in private storage.

## Options and layout

`./bootstrap.sh --help` shows the flags: `--skip-packages`, `--skip-dotfiles`, `--skip-system-config`, and `--skip-mounts`. Skipping packages also skips Waydroid, Fish, XDG directory, and MIME setup. Skipping dotfiles leaves audio MIME defaults alone because the managed cliamp launcher is required. The remaining phases can still change the machine.

`packages/` holds Pacman, AUR, and Flatpak manifests. `stow/` holds an explicit set of active user packages listed in `bootstrap.sh`; other directories do not deploy. The `codex` Stow package manages `~/.codex/AGENTS.md` and `~/.codex/config.toml` while leaving the rest of `~/.codex` local. The `waydroid` Stow package installs the custom Waydroid and Stop Waydroid launchers. Android app launchers generated by Waydroid stay outside Git and can be handled after private userdata is restored. `systemd/system/` holds the Synology units. Generated caches, histories, credentials, and mutable application state stay outside Git.

## Validation on a fresh KDE installation

Run the bootstrap twice and check its health report. Open an audio file with a name containing spaces and punctuation; test a KDE portal file dialog, a KWallet-backed personal app, network printer discovery, and both Synology automounts. On this working machine, validation is limited to static checks and isolated Stow dry runs; the bootstrap is never used as a test.
